The source repositories may have their own access settings. Their commit identifiers are provided for attribution; this public repository contains the curated source needed to run the submitted software. Existing exploratory work and assets include dates before the submission weekend. Publication here does not erase that history or constitute an eligibility determination by an organizer.

Imported files are snapshots. `source_worktree_changed: true` identifies a source file whose working copy differed from its recorded commit; the imported SHA-256 identifies the actual bytes used. Subsequent portability edits in this repository can differ from that imported hash and are recorded in this repository's Git history. The original checkouts and their uncommitted changes were left intact.

## AI assistance

Codex/ChatGPT assisted with code integration, test execution, documentation, presentation drafts, diagrams and this repository cleanup. AI assistance is not agronomic expert validation. Research metrics are derived from the retained evaluation artifacts and are labeled with their limitations. The NeuraX team remains responsible for reviewing the submission and its claims.

The team logo's transparent-background edit used image generation. NASA/Space Apps marks and third-party data retain their original rights. No claim of NASA endorsement is made.

## What was excluded

Virtual environments, `node_modules`, build output, run caches, raw publications, device logs with machine-specific details, private planning conversations and unrelated v5/v6 experiments are not part of this curated submission. Six compact selected climatology artifacts are included to reproduce v4 without retraining; source integrity is checked before loading them.
